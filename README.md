Ctrl+C Dashboard
Simple HTML-based dashboard to create, manage, and use custom copy-and-paste buttons. This tool is designed to enhance productivity in customer service environments by organizing frequently used responses and providing dynamic time-based greetings.

Overview
The Ctrl+C Dashboard is a client-side application that runs entirely in the web browser. It allows users to categorize text snippets, search through them efficiently, and copy content to the clipboard with a single click.

Key Features
Dynamic Greetings: Automatically generates "Bom dia", "Boa tarde", or "Boa noite" based on the user's system time.

User Customization: The greeting suffix and all other phrases can be edited by the user via a right-click menu.

Local Storage: All data, including custom phrases, categories, and theme preferences, are saved in the browser's local storage.

Privacy by Design: No data is sent to external servers; the application operates strictly on the user's machine.

Category Management: Users can create, rename, and delete categories to organize their snippets.

Data Portability: Features dedicated buttons to export and import data as JSON files for backup or sharing.

Dark Mode: Supports light and dark themes to suit different working environments.

Usage Instructions
Copying: Click any button to copy its text content directly to the clipboard.

Editing: Right-click on any phrase or category icon to modify its content.

Reordering: Hover the mouse over a phrase for 0.5 seconds to reveal management controls (Move Left, Move Right, or Delete).

Searching: Use the top search bar to filter phrases across all categories in real-time.

Backup: Use the Save icon in the footer to download a JSON file of your current configuration.

Technical Details
Language: Interface is in Portuguese (PT-BR).

Technologies: HTML5, CSS3, and Vanilla JavaScript.

Deployment: Compatible with GitHub Pages or any static file hosting service.
